# Fruits Corner - Freshness Lives Here 🍎🍊🍇

A modern, visually rich, and interactive fresh-fruit brand website built for **Fruits Corner**.

## Features
- **Faithful Hero Section**: Recreated visual layout, typography, colors, and rustic wood aesthetics.
- **Shop by Category**: Explore fruits by category with smooth hover animations and live catalog filtering.
- **Our Best Sellers**: Interactive product catalog with ratings, price per unit, wishlist toggling, and quick view modals.
- **Shopping Cart Drawer**: Slide-out cart with real-time +/- quantity updates, coupon code discounts (`FRESH20`), free delivery calculations, and checkout options.
- **Direct WhatsApp Ordering**: Automatically formats cart items and order total into a pre-filled WhatsApp message sent to `+91 63020 94687`.
- **Search Modal**: Real-time fruit search with quick-add functionality.
- **Location & Map**: Store locator with Google Maps-style preview card and one-click directions.
- **Responsive**: Seamless experience across mobile, tablet, and desktop screens.

## Getting Started

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
